# Brown Scholars Program

## Unit One: Earthquakes
- **Coding concepts:** Introduced to foundational coding concepts, including variables, data types, loops, and debugging common errors using Python.
- **Scientific concepts:** Learned the fundamentals of earthquakes, seismic waves and models, different lava types, tectonic plate speeds, Earth’s internal layers, and the various types of tectonic plate boundaries.
**Unit project:** Developed a map of recent earthquakes in Central America. Presented research on current earthquake activity and proposed plans to improve earthquake damage prevention and preparedness.

## Unit Three: Stars
- **Coding concepts:** Creating and working with pandas DataFrames, .loc[] indexing, creating histograms, Color–Magnitude Diagrams (CMDs), and data visualization with Matplotlib (matplotlib.colors)
- **Scientific concepts:** Stellar brightness and magnitude, calculating height using a clinometer, tycho–Gaia Astrometric Solution (TGAS), Hertzsprung–Russell (HR) diagram, and the Praesepe star cluster
- **Unit project:** Created a Color–Magnitude Diagram (CMD) for the Praesepe star cluster. Presented the history of Praesepe, explained the code, and interpreted the CMD.

## Unit Six: Covid-19
- **Coding concepts:** Handling live datasets, Plotly, and choropleth maps.
- **Scientific concepts:** COVID-19 cases, deaths, and recoveries.
- **Unit project:** Analyzed COVID-19 in the United States and its overall impact by plotting deaths, cases, and recoveries across the country. It included an in-depth analysis of COVID-19 testing in New York State, featuring one bar plot showing the number of tests conducted per day and another bar plot displaying the number of new positive cases per day. The project also involved a presentation focused on New York State, examining current events that influenced pandemic trends, the effects of age and culture, New York State regulations addressing COVID-19, and a clear explanation of the code and data models used.
